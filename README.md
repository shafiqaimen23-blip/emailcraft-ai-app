# EmailCraft AI

## Overview

EmailCraft AI is an AI-powered web application that helps users generate professional emails in seconds. Users enter the purpose of the email, choose a tone, and the AI generates a complete email instantly.

---

## Problem Solved

Many students, professionals, and job seekers find it difficult and time-consuming to write professional emails. EmailCraft AI solves this problem by generating polished emails within seconds.

## AI Feature

The application uses Artificial Intelligence to generate professional emails from a short user prompt.

### System Prompt

You are a professional email writing assistant. Generate clear, polite, grammatically correct, and well-structured emails based on the user's purpose and selected tone.
